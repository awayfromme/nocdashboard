# Contributing

Thanks for considering a contribution to NOC Dashboard. Bug reports, documentation improvements, accessibility fixes, and focused feature changes are welcome.

## Before you start

- Search existing issues and pull requests to avoid duplicating work.
- For larger changes, open an issue first to agree on the expected behavior.
- Never include `.env`, database dumps, credentials, or real operational data in a commit or issue.

## Development setup

Follow the local setup in [README.md](README.md). Keep backend and frontend changes focused, and document any new environment variables in both `.env.example` and the README. Do not put real secrets in `.env.example`.

## Pull requests

- Use a descriptive title and explain the problem and the user-visible change.
- Include setup or migration notes when configuration or data formats change.
- Add screenshots for visual changes where useful.
- State what you verified locally and list known limitations.
- Keep unrelated formatting or dependency changes out of the pull request.
